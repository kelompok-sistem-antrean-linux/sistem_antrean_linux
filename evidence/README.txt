DOKUMENTASI BUKTI PENGUJIAN
SISTEM ANTREAN LINUX

Folder ini berisi bukti pengujian berbentuk teks (.txt).
Setiap catatan disusun berdasarkan hasil pengujian yang sudah
terdokumentasi di repository.

DAFTAR BUKTI
1. anggota2-positif.txt
   Pengujian FIFO dan integrasi worker dengan sistem status.

2. anggota2-negatif.txt
   Pengujian lock, pekerjaan gagal, dan mekanisme retry.

3. anggota5-docker.txt
   Pengujian Docker read-only: container dapat membaca file,
   tetapi tidak dapat mengubah file host.

CATATAN
Bukti untuk anggota lain dapat ditambahkan setelah hasil
pengujiannya tersedia dan diverifikasi. File ini tidak
menggantikan dokumentasi teknis yang ada di folder docs/
dan anggota2/dokumentasi/.
